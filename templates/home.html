F A Q S
( Questions we are asked )

Everything about our pure Rust engine & streaming servers.

Setiap halaman tontonan dilengkapi dengan 5 server multi-provider (VidFast, VidLink, Vidy, VidZee, dan VidSrc). Cukup klik salah satu tombol server cadangan di bawah pemutar video untuk berpindah secara instan tanpa memuat ulang halaman.

Tidak perlu. Nonton menggunakan arsitektur Zero-Login LocalStorage. Seluruh daftar simpanan, episode terakhir yang ditonton, dan riwayat pencarian disimpan langsung di perangkat Anda dan dapat di-export/import sebagai file JSON kapan saja.

Seluruh backend dan template HTML dikompilasi langsung ke dalam satu binary native menggunakan Rust (Axum + Askama) dengan waktu render di bawah 1 milidetik, dipadukan dengan Lenis smooth inertial scroll engine.
